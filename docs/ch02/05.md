# 第 5 题　有限可加集函数的可列上界

**题目** 设 $\mu$ 是半环 $\mathscr{D}$ 上的非负有限可加集函数。证明：如果 $\{A_n\in\mathscr{D},n=1,2,\dots\}$ 两两不交，$A\in\mathscr{D}$ 且 $\bigcup_{n=1}^{\infty}A_n\subset A$，则
$$\sum_{n=1}^{\infty}\mu(A_n)\le\mu(A).$$

固定正整数 $N$。此时 $A_1,\dots,A_N$ 两两不交且都含于 $A$。

**把 $A$ 剖分成 $\mathscr{D}$ 中有限个不交集**。因 $r(\mathscr{D})$ 是环且含 $\mathscr{D}$，有
$$A\setminus\bigcup_{n=1}^{N}A_n\in r(\mathscr{D}).$$
由定理 1.3.2，存在两两不交的 $C_1,\dots,C_m\in\mathscr{D}$ 使
$$A\setminus\bigcup_{n=1}^{N}A_n=\bigsqcup_{j=1}^{m}C_j.$$
于是
$$A=A_1\sqcup\dots\sqcup A_N\sqcup C_1\sqcup\dots\sqcup C_m$$
是 $\mathscr{D}$ 中有限个两两不交集合之并，且并集 $A$ 本身属于 $\mathscr{D}$。

**用有限可加性**。由 $\mu$ 的有限可加性，
$$\mu(A)=\sum_{n=1}^{N}\mu(A_n)+\sum_{j=1}^{m}\mu(C_j)\ge\sum_{n=1}^{N}\mu(A_n),$$
最后一步用到 $\mu$ 非负。

上式对每个 $N$ 成立，令 $N\to\infty$ 即得
$$\sum_{n=1}^{\infty}\mu(A_n)\le\mu(A).$$
