# 第 7 题　上下极限集的测度

**题目** 设 $\mu$ 是 $\sigma$ 域 $\mathscr{F}$ 上的测度，对每个 $n=1,2,\dots$ 有 $A_n\in\mathscr{F}$。证明：
$$\mu\big(\liminf_{n\to\infty}A_n\big)\le\liminf_{n\to\infty}\mu(A_n);$$
如果 $\mu\big(\bigcup_{n=1}^{\infty}A_n\big)<\infty$，则还有
$$\mu\big(\limsup_{n\to\infty}A_n\big)\ge\limsup_{n\to\infty}\mu(A_n).$$

$\sigma$ 域是半环，故由定理 2.1.5，$\mu$ 具有单调性、下连续性和上连续性。

## 下极限

令
$$B_n=\bigcap_{k=n}^{\infty}A_k\in\mathscr{F},$$
则 $B_n\uparrow\liminf_nA_n$。由下连续性，
$$\mu\big(\liminf_{n\to\infty}A_n\big)=\lim_{n\to\infty}\mu(B_n).$$
又 $B_n\subset A_n$，由单调性 $\mu(B_n)\le\mu(A_n)$，故
$$\lim_{n\to\infty}\mu(B_n)=\liminf_{n\to\infty}\mu(B_n)\le\liminf_{n\to\infty}\mu(A_n).$$
两式合并即得第一个不等式。

## 上极限

令
$$C_n=\bigcup_{k=n}^{\infty}A_k\in\mathscr{F},$$
则 $C_n\downarrow\limsup_nA_n$，且
$$\mu(C_1)=\mu\Big(\bigcup_{n=1}^{\infty}A_n\Big)<\infty.$$
由上连续性，
$$\mu\big(\limsup_{n\to\infty}A_n\big)=\lim_{n\to\infty}\mu(C_n).$$
又 $A_n\subset C_n$，由单调性 $\mu(A_n)\le\mu(C_n)$，故
$$\limsup_{n\to\infty}\mu(A_n)\le\limsup_{n\to\infty}\mu(C_n)=\lim_{n\to\infty}\mu(C_n)
=\mu\big(\limsup_{n\to\infty}A_n\big).$$
