# 第 16 题　可数集的 L 测度

**题目** 证明：如果 $N$ 是 $R$ 中的有限或可数集，则其 L 测度为 $0$。对于一般的 L-S 测度，这一结论是否成立？

## L 测度的情形

L 测度 $\lambda$ 对应准分布函数 $F(x)=x$。

**单点集**：对任意 $x\in R$，
$$\{x\}=\bigcap_{n=1}^{\infty}\Big(x-\frac1n,\ x\Big],$$
右端是 $\mathscr{D}_R$ 中集合的递减交，故 $\{x\}\in\mathscr{B}_R\subset\mathscr{F}_\lambda$。又
$$\lambda\Big(\Big(x-\frac1n,x\Big]\Big)=x-\Big(x-\frac1n\Big)=\frac1n,$$
且 $\lambda((x-1,x])=1<\infty$，由上连续性得
$$\lambda(\{x\})=\lim_{n\to\infty}\frac1n=0.$$

**有限或可数集**：设 $N=\{x_1,x_2,\dots\}$（有限时同理）。诸单点集两两不交，由可列可加性
$$\lambda(N)=\sum_{n}\lambda(\{x_n\})=0.$$

## 一般 L-S 测度：结论不成立

设 $F$ 是准分布函数，$\lambda_F$ 是相应的 L-S 测度。与上面同样的计算给出
$$\lambda_F(\{x\})=\lim_{n\to\infty}\lambda_F\Big(\Big(x-\frac1n,x\Big]\Big)
=\lim_{n\to\infty}\Big[F(x)-F\Big(x-\frac1n\Big)\Big]=F(x)-F(x-0),$$
即单点集的 L-S 测度等于 $F$ 在该点的跃度。

**反例**：取
$$F(x)=\begin{cases}0,&x<0,\\ 1,&x\ge0,\end{cases}$$
它非降、右连续、实值，是准分布函数。此时 $N=\{0\}$ 是有限集，但
$$\lambda_F(\{0\})=F(0)-F(0-0)=1-0=1\ne0.$$

故对一般的 L-S 测度，有限或可数集的测度未必为 $0$。
