# 第 28 题　依分布收敛加依概率趋零

**题目** 证明：如果 $f_n\xrightarrow{d}f$ 而 $g_n\xrightarrow{P}0$，则 $f_n+g_n\xrightarrow{d}f$。

设 $F_n$、$F$ 分别是 $f_n$、$f$ 的分布函数，$H_n$ 是 $f_n+g_n$ 的分布函数，即
$$H_n(x)=P(f_n+g_n\le x).$$
要证 $H_n(x)\to F(x)$ 在 $F$ 的每个连续点 $x$ 成立。

以下固定 $F$ 的连续点 $x$，并任取 $\varepsilon>0$ 使 $x+\varepsilon$ 和 $x-\varepsilon$ 也是 $F$ 的连续点（$F$ 的不连续点至多可数，故这样的 $\varepsilon$ 可以取到任意小）。

## 上界

$$P(f_n+g_n\le x)\le P(f_n+g_n\le x,\ |g_n|<\varepsilon)+P(|g_n|\ge\varepsilon)
\le P(f_n\le x+\varepsilon)+P(|g_n|\ge\varepsilon),$$
即
$$H_n(x)\le F_n(x+\varepsilon)+P(|g_n|\ge\varepsilon).$$
令 $n\to\infty$，由 $F_n(x+\varepsilon)\to F(x+\varepsilon)$ 和 $P(|g_n|\ge\varepsilon)\to0$ 得
$$\limsup_{n\to\infty}H_n(x)\le F(x+\varepsilon).$$

## 下界

$$P(f_n\le x-\varepsilon)\le P(f_n\le x-\varepsilon,\ |g_n|<\varepsilon)+P(|g_n|\ge\varepsilon)
\le P(f_n+g_n\le x)+P(|g_n|\ge\varepsilon),$$
即
$$F_n(x-\varepsilon)-P(|g_n|\ge\varepsilon)\le H_n(x).$$
令 $n\to\infty$ 得
$$\liminf_{n\to\infty}H_n(x)\ge F(x-\varepsilon).$$

## 合并

于是对一切充分小的合适的 $\varepsilon>0$，
$$F(x-\varepsilon)\le\liminf_{n\to\infty}H_n(x)\le\limsup_{n\to\infty}H_n(x)\le F(x+\varepsilon).$$
令 $\varepsilon\downarrow0$（沿使 $x\pm\varepsilon$ 为 $F$ 连续点的一列 $\varepsilon$），由 $F$ 在 $x$ 连续得
$$F(x)\le\liminf_{n\to\infty}H_n(x)\le\limsup_{n\to\infty}H_n(x)\le F(x),$$
即 $H_n(x)\to F(x)$。

故 $H_n\xrightarrow{w}F$，即 $f_n+g_n\xrightarrow{d}f$。
