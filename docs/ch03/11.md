# 第 11 题　L1 收敛蕴含依测度收敛

**题目** 设 $\{f_n,n=1,2,\dots\}$ 和 $f$ 都是可测函数。证明：如果
$$\lim_{n\to\infty}\int_X|f_n-f|\mathrm{d}\mu=0,$$
则 $f_n\xrightarrow{\mu}f$；又如果 $\int_Xf_n\mathrm{d}\mu-\int_Xf\mathrm{d}\mu$ 有意义，则
$$\lim_{n\to\infty}\int_Xf_n\mathrm{d}\mu=\int_Xf\mathrm{d}\mu.$$

条件蕴含当 $n$ 充分大时 $\int_X|f_n-f|\mathrm{d}\mu<\infty$，故 $|f_n-f|$ 可积，从而 $|f_n-f|<\infty$ a.e.（定理 3.1.3 之 (3)），$f_n-f$ a.e. 有定义。

## 依测度收敛

任给 $\varepsilon>0$，把第 2 题用于可测函数 $f_n-f$，得
$$\mu(|f_n-f|\ge\varepsilon)\le\frac1\varepsilon\int_X|f_n-f|\mathrm{d}\mu.$$
右端趋于 $0$，故
$$\lim_{n\to\infty}\mu(|f_n-f|\ge\varepsilon)=0,\qquad\forall\varepsilon>0,$$
即 $f_n\xrightarrow{\mu}f$。

## 积分的收敛

设 $\int_Xf_n\mathrm{d}\mu-\int_Xf\mathrm{d}\mu$ 有意义，特别 $f_n$ 与 $f$ 的积分都存在。由定理 3.2.1 之 (1)，$-f$ 的积分存在且 $\int_X(-f)\mathrm{d}\mu=-\int_Xf\mathrm{d}\mu$，于是
$$\int_Xf_n\mathrm{d}\mu+\int_X(-f)\mathrm{d}\mu$$
有意义。由定理 3.2.1 之 (2)，$f_n-f$ 的积分存在且
$$\int_X(f_n-f)\mathrm{d}\mu=\int_Xf_n\mathrm{d}\mu-\int_Xf\mathrm{d}\mu.$$

再由定理 3.1.3 之 (1)，
$$\Big|\int_Xf_n\mathrm{d}\mu-\int_Xf\mathrm{d}\mu\Big|=\Big|\int_X(f_n-f)\mathrm{d}\mu\Big|\le\int_X|f_n-f|\mathrm{d}\mu\longrightarrow0.$$
故 $\int_Xf_n\mathrm{d}\mu\to\int_Xf\mathrm{d}\mu$。
