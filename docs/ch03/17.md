# 第 17 题　0 < p < 1 时的 Minkowski 不等式

**题目** 证明定理 3.3.7：如果 $0<p<1$，则 $\|f+g\|_p\le\|f\|_p+\|g\|_p$。

按教材约定，$0<p<1$ 时
$$\|f\|_p\overset{\text{def}}{=}\int_X|f|^p\mathrm{d}\mu,$$
与 $1\le p\le\infty$ 时的定义不同，这里不再取 $1/p$ 次方。

## 证明

设 $f,g\in L_p$。由 $\int_X|f|^p\mathrm{d}\mu<\infty$ 和定理 3.1.3 之 (3) 得 $|f|^p<\infty$ a.e.，即 $|f|<\infty$ a.e.；同理 $|g|<\infty$ a.e.。故 $f+g$ a.e. 有定义，不妨设它处处有定义。

由引理 3.3.6（第 16 题），逐点有
$$|f+g|^p\le|f|^p+|g|^p.$$

两端都是非负可测函数，由命题 3.1.2 之 (7) 和 (6)，
$$\int_X|f+g|^p\mathrm{d}\mu\le\int_X\big(|f|^p+|g|^p\big)\mathrm{d}\mu=\int_X|f|^p\mathrm{d}\mu+\int_X|g|^p\mathrm{d}\mu,$$
即
$$\|f+g\|_p\le\|f\|_p+\|g\|_p.$$

右端有限，故 $f+g\in L_p$。
