# 第 18 题　平均收敛不蕴含 a.e. 收敛

**题目** 举例说明：$f_n\xrightarrow{L_1}f$ 并不蕴含 $f_n\xrightarrow{\text{a.e.}}f$。

## 例子

取 $X=(0,1]$，$\mathscr{F}$ 是 $(0,1]$ 上的 Borel 集全体，$\mu=\lambda$ 是 L 测度。

每个正整数 $n$ 可以惟一地写成
$$n=2^k+j,\qquad k=0,1,2,\dots,\quad j=0,1,\dots,2^k-1.$$
令
$$f_n=I_{J_n},\qquad J_n=\Big(\frac j{2^k},\frac{j+1}{2^k}\Big],\qquad f=0.$$

对固定的 $k$，$\{J_n:2^k\le n<2^{k+1}\}$ 恰是把 $(0,1]$ 等分成 $2^k$ 段的分割。

## $f_n\xrightarrow{L_1}0$

$$\|f_n-f\|_1=\int_{(0,1]}I_{J_n}\mathrm{d}\lambda=\lambda(J_n)=\frac1{2^k}.$$
由 $n<2^{k+1}$ 得 $2^{-k}<\frac2n$，故
$$\|f_n-f\|_1<\frac2n\longrightarrow0,$$
即 $f_n\xrightarrow{L_1}0$。

## 每一点都不收敛

任取 $x\in(0,1]$ 和 $k\ge1$。因为 $\{J_n:2^k\le n<2^{k+1}\}$ 是 $(0,1]$ 的分割，$x$ 恰属于其中一个 $J_{n_k}$，于是
$$f_{n_k}(x)=1,\qquad2^k\le n_k<2^{k+1};$$
而这一组共有 $2^k\ge2$ 个区间，故其中还有一个 $J_{m_k}$ 不含 $x$，于是
$$f_{m_k}(x)=0,\qquad2^k\le m_k<2^{k+1}.$$

令 $k\to\infty$ 便有 $n_k\to\infty$ 和 $m_k\to\infty$，从而
$$\limsup_{n\to\infty}f_n(x)=1,\qquad\liminf_{n\to\infty}f_n(x)=0.$$

这对每个 $x\in(0,1]$ 都成立，即 $\{f_n\}$ 在 $(0,1]$ 上处处发散。于是不存在任何可测函数 $h$ 使 $f_n\xrightarrow{\text{a.e.}}h$，特别 $f_n\xrightarrow{\text{a.e.}}f$ 不成立。
