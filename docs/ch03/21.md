# 第 21 题　证明定理 3.4.1

**题目** 证明定理 3.4.1：设 $f$ 是概率空间 $(X,\mathscr{F},P)$ 上的随机变量，其分布函数为 $F$。则对任何 $(R,\mathscr{B}_R)$ 上的可测函数 $g$，$g\circ f$ 是 $(X,\mathscr{F},P)$ 上的可测函数，而且只要
$$\mathrm{E}(g\circ f)=\int_Rg\mathrm{d}F$$
之一端有意义，另一端也有意义而且等式成立。

## 可测性

$f$ 是 $(X,\mathscr{F})$ 到 $(R,\mathscr{B}_R)$ 的可测映射，$g$ 是 $(R,\mathscr{B}_R)$ 到 $(R,\mathscr{B}_R)$ 的可测映射，由定理 1.4.4（可测映射的复合仍可测）得 $g\circ f$ 是 $(X,\mathscr{F})$ 上的可测函数。

## $f$ 的像测度

把定理 3.2.10（第 8 题）用于可测映射 $f$：令
$$\nu(B)=P(f^{-1}B),\qquad B\in\mathscr{B}_R,$$
则 $(R,\mathscr{B}_R,\nu)$ 是测度空间，而且对 $(R,\mathscr{B}_R)$ 上的任何可测函数 $g$，只要
$$\int_Rg\mathrm{d}\nu=\int_Xg\circ f\mathrm{d}P=\mathrm{E}(g\circ f)$$
之一端有意义，等式就成立。

## $\nu$ 就是 $\lambda_F$

$F$ 是 $f$ 的分布函数，即 $F(x)=P(f\le x)$。于是对任何 $-\infty<a\le b<\infty$，
$$\nu\big((a,b]\big)=P(a<f\le b)=F(b)-F(a)=\lambda_F\big((a,b]\big).$$
即 $\nu$ 与 $\lambda_F$ 在
$$\mathscr{D}_R=\{(a,b]:-\infty<a\le b<\infty\}$$
上一致。$\mathscr{D}_R$ 是 $\pi$ 系而且 $\sigma(\mathscr{D}_R)=\mathscr{B}_R$。

命题 2.3.1 还要求存在两两不交的 $\{A_n\in\mathscr{D}_R\}$ 使 $\bigcup_nA_n=R$ 且各 $\nu(A_n)<\infty$。取
$$A_1=(-1,1],\qquad A_{2m}=(m,m+1],\qquad A_{2m+1}=(-m-1,-m],\qquad m=1,2,\dots$$
它们都属于 $\mathscr{D}_R$，两两不交，而且
$$(-\infty,-1]\cup(-1,1]\cup(1,\infty)=R,$$
即 $\bigcup_nA_n=R$。又每个 $A_n$ 的测度是 $F$ 在其两个端点处的差，都是有限数。

于是由命题 2.3.1（$\pi$ 系上的惟一性）得
$$\nu=\lambda_F\quad\text{在}\ \sigma(\mathscr{D}_R)=\mathscr{B}_R\ \text{上}.$$

## 结论

按 L-S 积分的定义 $\int_Rg\mathrm{d}F=\int_Rg\mathrm{d}\lambda_F$，故对任何 $(R,\mathscr{B}_R)$ 上的可测函数 $g$，
$$\mathrm{E}(g\circ f)=\int_Rg\mathrm{d}\nu=\int_Rg\mathrm{d}\lambda_F=\int_Rg\mathrm{d}F,$$
而且由定理 3.2.10 的结论，只要一端有意义，另一端就有意义。

取 $g(x)=x^k$ 和 $g(x)=(x-\mathrm{E}f)^k$ 即分别得到教材中矩与中心矩的计算公式。
