# 第 5 题　存在控制可列个有限测度的测度

**题目** 设 $\{\mu_n\}$ 是非 $0$ 的有限测度列。证明：存在有限测度 $\mu$ 使对每个 $n=1,2,\dots$ 有 $\mu_n\ll\mu$。

## 构造

$\mu_n$ 非 $0$ 且有限，故
$$0<\mu_n(X)<\infty.$$
对每个 $A\in\mathscr{F}$ 令
$$\mu(A)=\sum_{n=1}^{\infty}\frac1{2^n}\cdot\frac{\mu_n(A)}{\mu_n(X)}.$$

## $\mu$ 是有限测度

$\mu$ 非负，且 $\mu(\varnothing)=\sum_n2^{-n}\cdot0=0$。

设 $\{A_k\in\mathscr{F},k=1,2,\dots\}$ 两两不交。由每个 $\mu_n$ 的可列可加性，
$$\mu\Big(\bigcup_{k=1}^{\infty}A_k\Big)=\sum_{n=1}^{\infty}\frac1{2^n\mu_n(X)}\sum_{k=1}^{\infty}\mu_n(A_k)
=\sum_{k=1}^{\infty}\sum_{n=1}^{\infty}\frac{\mu_n(A_k)}{2^n\mu_n(X)}=\sum_{k=1}^{\infty}\mu(A_k),$$
中间一步交换求和次序是允许的，因为各项非负。故 $\mu$ 是测度。

又
$$\mu(X)=\sum_{n=1}^{\infty}\frac1{2^n}\cdot\frac{\mu_n(X)}{\mu_n(X)}=\sum_{n=1}^{\infty}\frac1{2^n}=1<\infty,$$
再由单调性知 $\mu(A)\le1$ 对一切 $A\in\mathscr{F}$ 成立，即 $\mu$ 是有限测度。

## $\mu_n\ll\mu$

设 $A\in\mathscr{F}$ 满足 $\mu(A)=0$。$\mu(A)$ 是非负项级数的和，故每一项都为 $0$，即
$$\frac{\mu_n(A)}{2^n\mu_n(X)}=0,\qquad n=1,2,\dots$$
由 $0<\mu_n(X)<\infty$ 得 $\mu_n(A)=0$。

这对每个 $n$ 成立，即 $\mu_n\ll\mu$ 对每个 $n=1,2,\dots$ 成立。
