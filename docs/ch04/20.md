# 第 20 题　完成引理 4.5.1 的证明

**题目** 完成引理 4.5.1 的证明。

引理 4.5.1 是：设随机变量 $f$ 的积分存在。如果 $\sigma(f)$ 与集合系 $\mathscr{E}\subset\mathscr{F}$ 独立，则对任何 $A\in\mathscr{E}$ 有
$$\mathrm{E}fI_A=\mathrm{E}f\cdot P(A).$$

以下固定 $A\in\mathscr{E}$。注意 $(fI_A)^\pm=f^\pm I_A\le f^\pm$，由命题 3.1.2 之 (7) 和定义 3.1.1 知 $fI_A$ 的积分也存在。

$P(A)=0$ 时 $fI_A=0$ a.s.，由定理 3.1.4 之 (3) 得 $\mathrm{E}fI_A=0$，而右端按 $\infty\cdot0=0$ 的约定也是 $0$，等式成立。以下设 $P(A)>0$。

用典型方法。

## 第一步：$f=I_B$，$B\in\sigma(f)$

$\sigma(f)$ 与 $\mathscr{E}$ 独立，故 $B$ 与 $A$ 独立，
$$\mathrm{E}I_BI_A=\mathrm{E}I_{B\cap A}=P(B\cap A)=P(B)P(A)=\mathrm{E}I_B\cdot P(A).$$

## 第二步：$f$ 是非负简单的 $\sigma(f)$ 可测函数

设 $f=\sum_{i=1}^{m}c_iI_{B_i}$，其中 $c_i\ge0$，$\{B_i\}$ 是 $(X,\sigma(f))$ 的有限可测分割。则 $fI_A=\sum_ic_iI_{B_i\cap A}$ 也是非负简单函数，由命题 3.1.1 之 (3) 和 (4) 及第一步，
$$\mathrm{E}fI_A=\sum_{i=1}^{m}c_iP(B_i\cap A)=\sum_{i=1}^{m}c_iP(B_i)P(A)=\mathrm{E}f\cdot P(A).$$

## 第三步：$f\ge0$

$f$ 关于 $\sigma(f)$ 可测。由定理 1.5.3 取非负简单函数列 $f_n\uparrow f$，其中 $f_n$ 是 $f$ 的函数，故都关于 $\sigma(f)$ 可测。于是 $f_nI_A\uparrow fI_A$，两次用单调收敛定理 3.2.4 并借助第二步，
$$\mathrm{E}fI_A=\lim_{n\to\infty}\mathrm{E}f_nI_A=\lim_{n\to\infty}\mathrm{E}f_n\cdot P(A)=\mathrm{E}f\cdot P(A).$$

## 第四步：$f$ 是一般随机变量

$f^+$ 与 $f^-$ 都是非负的 $\sigma(f)$ 可测函数，由第三步
$$\mathrm{E}f^+I_A=\mathrm{E}f^+\cdot P(A),\qquad\mathrm{E}f^-I_A=\mathrm{E}f^-\cdot P(A).$$
$f$ 的积分存在，即 $\min\{\mathrm{E}f^+,\mathrm{E}f^-\}<\infty$；由 $P(A)>0$ 知上面两个乘积中也至少有一个有限，可以相减。于是由 (3.1.5) 式
$$\mathrm{E}fI_A=\mathrm{E}f^+I_A-\mathrm{E}f^-I_A=\big(\mathrm{E}f^+-\mathrm{E}f^-\big)P(A)=\mathrm{E}f\cdot P(A).$$
