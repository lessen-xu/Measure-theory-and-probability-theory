# 第 23 题　离散随机变量给定值的条件概率

**题目** 证明 (4.5.7) 式。

(4.5.7) 式是：当 $g$ 是一个离散型随机变量，其取值和取值概率分别为 $\{a_1,a_2,\dots\}$ 和 $\{p_n=P(g=a_n)>0,n=1,2,\dots\}$ 时，对任何 $A\in\mathscr{F}$ 有
$$P(A|g=a_n)=\frac{P\big(A\cap\{g=a_n\}\big)}{P(g=a_n)}.$$

## 定义的回顾

$g$ 是随机变量，故它取值的可测空间就是 $(R,\mathscr{B}_R)$。按定义 4.5.3 及其后关于条件概率的约定，
$$P(A|g=\cdot)=\mathrm{E}(I_A|g=\cdot)$$
是 $(R,\mathscr{B}_R)$ 上的可测函数，记作 $h$，它满足 (4.5.6) 式：对任意 $B\in\mathscr{B}_R$
$$\int_{g^{-1}B}I_A\mathrm{d}P=\int_Bh(y)(Pg^{-1})(\mathrm{d}y).$$

## 取 $B=\{a_n\}$

**左端**
$$\int_{g^{-1}\{a_n\}}I_A\mathrm{d}P=P\big(A\cap\{g=a_n\}\big).$$

**右端**　$hI_{\{a_n\}}=h(a_n)I_{\{a_n\}}$，由命题 3.1.1 之 (1) 和 (3)
$$\int_{\{a_n\}}h\mathrm{d}(Pg^{-1})=h(a_n)\cdot(Pg^{-1})(\{a_n\})=h(a_n)P(g=a_n)=h(a_n)p_n.$$

## 结论

于是
$$h(a_n)p_n=P\big(A\cap\{g=a_n\}\big).$$
由 $p_n=P(g=a_n)>0$ 两端除以 $p_n$，
$$P(A|g=a_n)=h(a_n)=\frac{P\big(A\cap\{g=a_n\}\big)}{P(g=a_n)},$$
这正是 (4.5.7) 式。它与初等概率论中事件 $A$ 关于事件 $\{g=a_n\}$ 的条件概率完全一致。
