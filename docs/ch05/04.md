# 第 4 题　完成定理 5.1.4 之 (2) 的证明

**题目** 用典型方法完成定理 5.1.4 之 (2) 的证明。

定理 5.1.4 之 (2) 是：对任意固定的 $1\le k_1<\dots<k_i\le n$ 和 $(x_{k_1},\dots,x_{k_i})\in\prod_{j=1}^{i}X_{k_j}$，乘积可测空间 $\big(\prod_{k=1}^{n}X_k,\prod_{k=1}^{n}\mathscr{F}_k\big)$ 上的可测函数 $f$ 在 $(x_{k_1},\dots,x_{k_i})$ 处的截口是 $\mathscr{F}|_{k_1,\dots,k_i}$ 可测函数。

照教材的做法只对 $n=2$、$i=1$ 来写，一般情形的论证完全一样，只是记号麻烦一些。以下固定 $x_1\in X_1$，记 $f|_{x_1}=f(x_1,\cdot)$，要证它是 $(X_2,\mathscr{F}_2)$ 上的可测函数。定理 5.1.4 之 (1) 即 (5.1.2) 式已经给出：
$$A\in\mathscr{F}_1\times\mathscr{F}_2\implies A|_{x_1}\in\mathscr{F}_2.\tag{1}$$

## 第一步：指示函数

设 $f=I_A$，$A\in\mathscr{F}_1\times\mathscr{F}_2$。对每个 $x_2\in X_2$，
$$f(x_1,x_2)=I_A(x_1,x_2)=1\iff(x_1,x_2)\in A\iff x_2\in A|_{x_1},$$
故
$$f|_{x_1}=I_{A|_{x_1}}.$$
由 (1) 式 $A|_{x_1}\in\mathscr{F}_2$，故 $f|_{x_1}$ 是 $\mathscr{F}_2$ 可测的。

## 第二步：非负简单函数

设 $f=\sum_{r=1}^{m}a_rI_{A_r}$，其中 $a_r\ge0$，$\{A_r\in\mathscr{F}_1\times\mathscr{F}_2,r=1,\dots,m\}$ 是 $X_1\times X_2$ 的有限可测分割。由第 2 题，$\{A_r|_{x_1}\}$ 两两不交且
$$\bigcup_{r=1}^{m}A_r|_{x_1}=\Big(\bigcup_{r=1}^{m}A_r\Big)\Big|_{x_1}=(X_1\times X_2)|_{x_1}=X_2,$$
再由 (1) 式，$\{A_r|_{x_1}\}$ 是 $X_2$ 的有限可测分割。于是
$$f|_{x_1}=\sum_{r=1}^{m}a_rI_{A_r|_{x_1}}$$
是 $(X_2,\mathscr{F}_2)$ 上的非负简单函数，当然可测。

## 第三步：非负可测函数

设 $f\ge0$ 可测。由定理 1.5.3 之 (1)，存在非负简单函数列 $\{f_m\}$ 使 $f_m\uparrow f$。取截口是逐点进行的，故对每个 $x_2\in X_2$
$$f_m(x_1,x_2)\uparrow f(x_1,x_2),$$
即 $f_m|_{x_1}\uparrow f|_{x_1}$。由第二步每个 $f_m|_{x_1}$ 是 $\mathscr{F}_2$ 可测的，故由定理 1.5.2 它们的极限 $f|_{x_1}$ 也是 $\mathscr{F}_2$ 可测的。

## 第四步：一般可测函数

设 $f$ 可测。逐点有
$$(f^{\pm})|_{x_1}=(f|_{x_1})^{\pm},$$
而 $f^+$ 与 $f^-$ 都是非负可测函数，由第三步 $(f|_{x_1})^+$ 与 $(f|_{x_1})^-$ 都是 $\mathscr{F}_2$ 可测的。$f|_{x_1}=(f|_{x_1})^+-(f|_{x_1})^-$ 处处有意义，由定理 1.5.1 之 (2) 知 $f|_{x_1}$ 可测。

对固定的 $x_2\in X_2$ 讨论 $f|_{x_2}=f(\cdot,x_2)$ 时论证对称。定理 5.1.4 之 (2) 得证。
