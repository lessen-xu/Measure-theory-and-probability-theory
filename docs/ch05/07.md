# 第 7 题　一个含参积分的计算

**题目** 对任何 $0<a<b<\infty$，证明：
$$\int_0^1\frac{x^b-x^a}{\ln x}\mathrm{d}x=\ln\frac{1+b}{1+a}.$$

## 把被积函数写成一个积分

对每个 $x\in(0,1)$ 有 $\ln x<0$，而且
$$\frac{\partial}{\partial y}x^y=x^y\ln x,$$
$y\mapsto x^y$ 在 $[a,b]$ 上连续，故由 Newton-Leibniz 公式与第三章第 23 题（取 $F(y)=y$）
$$\int_a^bx^y\mathrm{d}y=\frac{x^y}{\ln x}\Big|_{y=a}^{y=b}=\frac{x^b-x^a}{\ln x},\qquad x\in(0,1).\tag{1}$$

## 一个非负可测函数

在 $(R^2,\mathscr{B}_R^2)$ 上令
$$h(x,y)=\begin{cases}x^y,&(x,y)\in G,\\[2pt]0,&(x,y)\notin G,\end{cases}\qquad G=(0,1)\times(a,b).$$
$G$ 是 $R^2$ 中的开集，故 $G\in\mathscr{B}_R^2$；$x^y=\mathrm{e}^{y\ln x}$ 在 $G$ 上连续。于是对每个 $c\in R$
$$\{h>c\}=\begin{cases}R^2,&c<0,\\[2pt]G,&c=0,\\[2pt]\{(x,y)\in G:x^y>c\},&c>0,\end{cases}$$
其中 $c>0$ 时的集合是连续函数在开集上的原像因而是开集。故 $h$ 是 $\mathscr{B}_R^2$ 可测的非负函数。

## 交换积分次序

$R$ 上的 L 测度 $\lambda$ 是 $\sigma$ 有限的，$h\ge0$ 的重积分总存在，由 Fubini 定理 5.1.7 之 (2)，两个累次积分都等于重积分因而彼此相等：
$$\int_R\lambda(\mathrm{d}x)\int_Rh(x,y)\lambda(\mathrm{d}y)=\int_R\lambda(\mathrm{d}y)\int_Rh(x,y)\lambda(\mathrm{d}x).\tag{2}$$

**左端**　$x\notin(0,1)$ 时内层积分为 $0$；$x\in(0,1)$ 时由 (1) 式内层积分等于 $\dfrac{x^b-x^a}{\ln x}$。故 (2) 式左端为
$$\int_{(0,1)}\frac{x^b-x^a}{\ln x}\lambda(\mathrm{d}x).$$
端点 $0$ 与 $1$ 组成 L 零测集，由定理 3.1.4 它就是题中的 $\int_0^1\frac{x^b-x^a}{\ln x}\mathrm{d}x$。

**右端**　$y\notin(a,b)$ 时内层积分为 $0$；$y\in(a,b)$ 时 $x\mapsto x^y$ 在 $[0,1]$ 上连续，由第三章第 23 题
$$\int_Rh(x,y)\lambda(\mathrm{d}x)=\int_0^1x^y\mathrm{d}x=\frac1{1+y}.$$
再对 $y$ 积分，同样用第三章第 23 题，
$$\int_a^b\frac{\mathrm{d}y}{1+y}=\ln(1+b)-\ln(1+a)=\ln\frac{1+b}{1+a}.$$

## 结论

由 (2) 式两端相等，
$$\int_0^1\frac{x^b-x^a}{\ln x}\mathrm{d}x=\ln\frac{1+b}{1+a}.$$
