## 记号与定义约定（教材 §1–§4）

### §1 有限维乘积空间

- **乘积与投影**：$\prod_{k=1}^{n}X_k=\{(x_1,\dots,x_n):x_k\in X_k\}$，$\pi_k(x_1,\dots,x_n)=x_k$；一般的投影 $\pi_{k_1,\dots,k_i}=(\pi_{k_1},\dots,\pi_{k_i})$。
- **可测矩形与乘积 $\sigma$ 域**：$\mathscr{Q}=\{\prod_kA_k:A_k\in\mathscr{F}_k\}$，$\prod_k\mathscr{F}_k=\sigma(\mathscr{Q})$。**命题 5.1.1**：$\mathscr{Q}$ 是半环且 $\prod_kX_k\in\mathscr{Q}$。
- **命题 5.1.2**：(1) 每个 $\pi_k$ 可测（(5.1.1) 式）；(2) $\prod_k\mathscr{F}_k=\sigma\big(\bigcup_k\pi_k^{-1}\mathscr{F}_k\big)$。**定理 5.1.3**：$f=(f_1,\dots,f_n)$ 可测当且仅当每个 $f_k$ 可测；概率论中即随机向量与其分量的关系。
- **截口**：$A|_{x_1,\dots,x_i}=\{(x_{i+1},\dots,x_n):(x_1,\dots,x_n)\in A\}$，$f|_{x_1,\dots,x_i}=f(x_1,\dots,x_i,\cdot,\dots,\cdot)$。**定理 5.1.4**：可测集的截口可测（(5.1.2) 式），可测函数的截口可测。
- **转移函数**（定义 5.1.1）：$\Omega\times\mathscr{F}$ 上的广义实值函数 $p$，$p(\omega,\cdot)$ 是 $\mathscr{F}$ 上的测度而 $p(\cdot,A)$ 是 $\mathscr{S}$ 可测函数。存在 $\mathscr{F}$ 的可测分割 $\{A_n\}$ 使 $p(\omega,A_n)<\infty$ 对一切 $\omega$ 与 $n$ 成立时称 **$\sigma$ 有限**；$p(\omega,X)\equiv1$ 时称**概率转移函数**。
- **引理 5.1.5**：$p$ 是 $\sigma$ 有限转移函数、$f\ge0$ 可测时，$\int_{X_2}f(\cdot,x_2)p(\cdot,\mathrm{d}x_2)$ 关于 $\mathscr{F}_1$ 可测；(5.1.3) 式。
- **定理 5.1.6**：由 $(X_1,\mathscr{F}_1)$ 上的测度 $\mu_1$ 与 $\sigma$ 有限转移函数 $p$ 在乘积空间上造出测度 $\mu$，满足 (5.1.4) 式
  $$\mu(A_1\times A_2)=\int_{A_1}p(x_1,A_2)\mu_1(\mathrm{d}x_1);$$
  积分存在时有累次积分公式 (5.1.5) 式；$\mu_1$ $\sigma$ 有限时 $\mu$ 惟一且 $\sigma$ 有限。
- **定理 5.1.7（Fubini 定理）**：$\sigma$ 有限测度空间之积上存在惟一的**乘积测度** $\mu_1\times\mu_2$ 满足 (5.1.7) 式 $\mu(A_1\times A_2)=\mu_1(A_1)\mu_2(A_2)$；重积分存在时两个累次积分都等于它。$\sigma$ 有限性不可去（§1 例 1），重积分不存在时两个累次积分可以不等（§1 例 2）。
- **推论 5.1.8（分部积分公式）**：准分布函数 $F,G$ 与 $a\le b$，
  $$\int_{(a,b]}F(x)G(\mathrm{d}x)=FG\Big|_a^b-\int_{(a,b]}G(x-0)F(\mathrm{d}x).$$
- **定理 5.1.9** 与**定理 5.1.10**：定理 5.1.6 与定理 5.1.7 向 $n$ 维的推广，后者中累次积分可按 $1,\dots,n$ 的任一重新排列进行。

### §2 多维 Lebesgue-Stieltjes 测度

- $a\le b$ 与 $a<b$ 都指逐个坐标成立，$(a,b]=\{x\in R^n:a<x\le b\}$。**命题 5.2.1**：$\mathscr{D}_{R^n}=\{(a,b]:a,b\in R^n\}$ 是 $R^n$ 上的半环。
- **准分布函数**（定义 5.2.1）：$R^n$ 上的实值函数 $F$，关于每个变量右连续，而且 $n$ 次增量非负，即 (5.2.1) 式
  $$\sum_{c\in C}(-1)^{n(c)}F(c)\ge0\qquad(a\le b),$$
  其中 $C=\{c:c_i=a_i\ \text{或}\ b_i\}$，$n(c)=\#\{i:c_i=a_i\}$。$n=2$ 时它就是二次增量 $\Delta^2_{(a,b]}F\ge0$。
- **命题 5.2.2**：$\mu_F((a,b])$ 取 $n$ 次增量（$(a,b]$ 为空时取 $0$）是半环 $\mathscr{D}_{R^n}$ 上的测度；它产生的测度 $\lambda_F$ 称为 **$n$ 维 L-S 测度**，$F=x_1\cdots x_n$ 时称 **$n$ 维 L 测度**。
- **$n$ 元分布函数**：准分布函数加上 $\lim_{x_1,\dots,x_n\to\infty}F=1$ 与每个 $\lim_{x_i\to-\infty}F=0$。随机向量的**分布函数**（**联合分布函数**）与**边缘分布函数**。**命题 5.2.3**：随机向量的分布函数是 $n$ 元分布函数，反之每个 $n$ 元分布函数都有随机向量与之对应。
- **独立性**（教材第 117 页）：事件族 $\{A_t\}$ 独立指任意有限个的概率成乘积；事件系族 $\{\mathscr{E}_t\}$ 独立指从每个 $\mathscr{E}_t$ 中任取一个集合得到的事件族独立；随机变量族 $\{f_t\}$ 独立指 $\{\sigma(f_t)\}$ 独立。
- **定理 5.2.4**：$\pi$ 系族独立蕴含生成的 $\sigma$ 域族独立；(5.2.2) 式。**推论 5.2.5**：独立子 $\sigma$ 域族按指标分组后仍独立。**推论 5.2.6**：随机变量族独立的四个等价刻画。**命题 5.2.7**：$f_1,\dots,f_n$ 独立当且仅当 $Pf^{-1}=\prod_kPf_k^{-1}$。

### §3 可列维乘积空间的概率测度

- $\mathscr{Q}_{(n)}=\{\prod_{k\le n}A_k\}$，$\mathscr{Q}_{[n]}=\{A\times\prod_{k>n}X_k:A\in\mathscr{Q}_{(n)}\}$，$\mathscr{Q}=\bigcup_n\mathscr{Q}_{[n]}$（**有限维可测矩形柱集**）；$X_{(n)}=\prod_{k\le n}X_k$，$\mathscr{F}_{(n)}=\prod_{k\le n}\mathscr{F}_k$，$\mathscr{A}_{[n]}=\{A_{(n)}\times\prod_{k>n}X_k:A_{(n)}\in\mathscr{F}_{(n)}\}$，$\mathscr{A}=\bigcup_n\mathscr{A}_{[n]}$（**有限维可测柱集**）；(5.3.1) 式 $\mathscr{Q}_{[n]}=\pi_{(n)}^{-1}\mathscr{Q}_{(n)}$、$\mathscr{A}_{[n]}=\pi_{(n)}^{-1}\mathscr{F}_{(n)}$。
- **命题 5.3.1**：(1) $\mathscr{Q}$ 是半环且 $\prod_nX_n\in\mathscr{Q}$；(2) $\mathscr{A}$ 是域；(3) $\prod_n\mathscr{F}_n=\sigma(\mathscr{Q})=\sigma(\mathscr{A})=\sigma\big(\bigcup_n\pi_n^{-1}\mathscr{F}_n\big)$。
- **定理 5.3.2（Tulcea 定理）**：由 $P_1$ 与一列概率转移函数 $p_k$ 在可列维乘积可测空间上得惟一的概率测度 $P$，满足 (5.3.2) 式。**定理 5.3.3（Kolmogorov 定理）**：一列概率空间的乘积测度存在惟一。

### §4 任意无穷维乘积空间的概率测度

- $\mathscr{D}$ 是 $T$ 的有限子集系，$\mathscr{D}_n$ 是含 $n$ 个元素的子集系，$\mathscr{N}$ 是 $T$ 的可列子集系；投影 $\pi_S$ 与 $\pi^{T_0}_S$。**有限维可测矩形柱集** $\mathscr{Q}$ 生成 $\prod_{t\in T}\mathscr{F}_t$；**有限维可测柱集** $\mathscr{A}$；**可列维可测柱集** $\mathscr{F}_0$。
- **命题 5.4.1**：$\mathscr{Q}_S=\{\prod_{t\in S}A_t\}$ 是半环。**命题 5.4.2**：$\mathscr{Q}$ 是半环，证明中的**底放大法**后面反复使用。**命题 5.4.3**：$\mathscr{A}$ 是域。**命题 5.4.4**：$\prod_{t\in T}\mathscr{F}_t=\sigma\big(\bigcup_t\pi_t^{-1}\mathscr{F}_t\big)=\sigma(\mathscr{A})=\mathscr{F}_0$。
- **定理 5.4.5**：$f=\{f_t,t\in T\}$ 可测当且仅当每个 $f_t$ 可测。$T\subset R$ 时这样的 $f$ 称为 $T$ 上的**随机过程**，$f(\omega)$ 称为它的一条**轨道**。
- **相容有限维概率测度族**（定义 5.4.1）：(1) 每个 $P_{t_1,\dots,t_n}$ 是 $\mathscr{B}_R^n$ 上的概率测度；(2) 重排一致；(3) 加一维取 $R$ 后与低一维的一致。
- **引理 5.4.6** 与**引理 5.4.7**：先在 $(R^{\infty},\mathscr{B}_R^{\infty})$ 上用正则条件分布造转移函数再用 Tulcea 定理，得 $T=\{1,2,\dots\}$ 时的存在性；(5.4.7) 式。
- **定理 5.4.8（Kolmogorov 定理）**：任意无穷集 $T$ 上的相容有限维概率测度族决定 $(R^T,\mathscr{B}_R^T)$ 上惟一的概率测度 $P$，满足 (5.4.8) 式 $P\pi_S^{-1}(A)=P_S(A)$。**定理 5.4.9**：任意无穷个 $(R,\mathscr{B}_R)$ 上概率测度的乘积测度存在惟一。
