# 第 2 题　级数和等于给定随机变量是否为尾事件

**题目** 设 $\{f_n,n=1,2,\dots\}$ 是随机变量序列，$f$ 是一个随机变量。试问：$\big\{\sum_{n=1}^{\infty}f_n=f\big\}$ 是不是尾事件，为什么？

## 结论

不是。下面给出反例。

## 反例

设 $X$ 是一个非空集合，$A\ne\varnothing$ 是它的真子集，令
$$\mathscr{F}=\{\varnothing,A,A^c,X\},$$
它显然是 $X$ 上的 $\sigma$ 域。在 $\mathscr{F}$ 上取概率测度 $P$ 使 $P(A)=1/2$（例如 $P(\varnothing)=0$、$P(A)=P(A^c)=1/2$、$P(X)=1$，可列可加性易验证）。在概率空间 $(X,\mathscr{F},P)$ 上取
$$f_1=f_2=\dots=f_n=\dots=0,\qquad f=I_A.$$
$A\in\mathscr{F}$，故 $f$ 是随机变量；常值函数当然是随机变量。

**尾 $\sigma$ 域**　每个 $f_n$ 恒为 $0$，故 $\sigma(f_n)=\{\varnothing,X\}$，从而对每个 $k$
$$\mathscr{G}_k=\sigma(\{f_n,n\ge k\})=\{\varnothing,X\},\qquad\mathscr{G}=\bigcap_{k=1}^{\infty}\mathscr{G}_k=\{\varnothing,X\}.$$

**所论的事件**　$\sum_{n=1}^{\infty}f_n=0$ 处处成立，而 $I_A=0$ 当且仅当 $x\in A^c$，故
$$\Big\{\sum_{n=1}^{\infty}f_n=f\Big\}=A^c.$$
$A$ 是 $X$ 的非空真子集，故 $A^c\ne\varnothing$ 且 $A^c\ne X$，于是
$$A^c\notin\{\varnothing,X\}=\mathscr{G},$$
即这个事件不是尾事件。

## 用零壹律的另一个证法

常值随机变量列 $\{f_n\}$ 是相互独立的：对任意 $n$ 与 $A_k\in\sigma(f_k)=\{\varnothing,X\}$，$P\big(\bigcap_kA_k\big)=\prod_kP(A_k)$ 直接可验。由 Kolmogorov 零壹律（定理 6.1.1），$\{f_n\}$ 的每个尾事件概率非 $0$ 即 $1$。而
$$P\Big(\Big\{\sum_{n=1}^{\infty}f_n=f\Big\}\Big)=P(A^c)=\frac12,$$
这也说明它不可能是尾事件。
