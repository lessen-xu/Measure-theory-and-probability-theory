# 第 4 题　适当正则化后 a.s. 趋于零

**题目** 证明：对任何随机变量序列 $\{f_n,n=1,2,\dots\}$，存在实数列 $\{a_n>0\}$ 和 $\{b_n\}$ 使
$$(f_n-b_n)/a_n\xrightarrow{\text{a.s.}}0.$$

## 取常数

固定 $n$。$f_n$ 取实值，故
$$\{|f_n|\ge M\}\downarrow\varnothing\qquad(M\to\infty,\ M\ \text{取正整数}),$$
$P$ 是有限测度，由上连续性 $P(|f_n|\ge M)\to0$。于是可以取正数 $M_n$ 使
$$P(|f_n|\ge M_n)<\frac1{2^n}.$$
令
$$a_n=nM_n>0,\qquad b_n=0.$$

## 验证第 3 题的条件

固定 $\varepsilon>0$，取正整数 $n_0>1/\varepsilon$。当 $n\ge n_0$ 时 $\varepsilon\ge1/n$，故
$$\Big\{\frac{|f_n-b_n|}{a_n}\ge\varepsilon\Big\}=\Big\{|f_n|\ge\varepsilon nM_n\Big\}\subset\{|f_n|\ge M_n\},$$
从而
$$\sum_{n=n_0}^{\infty}P\Big(\frac{|f_n-b_n|}{a_n}\ge\varepsilon\Big)\le\sum_{n=n_0}^{\infty}P(|f_n|\ge M_n)\le\sum_{n=n_0}^{\infty}\frac1{2^n}<\infty.$$
前面有限个 $n$ 的项当然有限，故
$$\sum_{n=1}^{\infty}P\Big(\frac{|f_n-b_n|}{a_n}\ge\varepsilon\Big)<\infty$$
对每个 $\varepsilon>0$ 成立。

## 结论

由第 3 题用于随机变量序列 $\{(f_n-b_n)/a_n\}$，
$$(f_n-b_n)/a_n\xrightarrow{\text{a.s.}}0.$$
